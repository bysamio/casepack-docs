## Command Palette (Cmd+K)

Press **Cmd+K** (or **Ctrl+K** on Windows/Linux) to open the command palette:

- **Search incidents** by title or ID (up to 6 matches shown dynamically)
- **Navigate to any page** instantly
- Use **Arrow keys** to navigate results, **Enter** to select, **Escape** to close

### Command Palette Pages

| Page | Visibility |
|------|------------|
| Dashboard | All users |
| Incidents | All users |
| New Incident | All users |
| Overdue Milestones | All users |
| Webhooks | Owner / Admin only |
| Audit Log | Owner / Admin only |
| Tenants | CasePack Admin+ |
| Account Users | CasePack Admin+ |
| Customers | Super Admin only |

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| **Cmd+K** / **Ctrl+K** | Open command palette |
| **Cmd+I** / **Ctrl+I** | Create new incident |
| **Escape** | Close dialogs, command palette |

## Page-Specific Shortcuts

### Incident List

| Shortcut | Action |
|----------|--------|
| **N** | Navigate to create new incident |
| **/** | Focus the search input |

### Incident Detail

| Shortcut | Action |
|----------|--------|
| **Ctrl+U** / **Cmd+U** | Open file picker to upload evidence |
| **Cmd+Enter** / **Ctrl+Enter** | Save the currently-edited Description, Root Cause, or Lessons Learned field |
| **Escape** | Cancel inline editing of any field |

## Tips & Best Practices

- Learn **Cmd+K** — it's the single most useful shortcut for navigation
- **Cmd+I** creates incidents from any page without navigating first
- Use **N** and **/** on the incident list page for fast keyboard-driven workflow
- The command palette search is dynamic — incident results update as you type
